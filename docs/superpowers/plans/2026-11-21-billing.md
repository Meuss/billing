# Billing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-user Laravel + Filament app to manage Clients, Projects, Tasks, Time Entries and Expenses, and to produce branded CHF Invoices as PDFs, replacing Invoice Ninja.

**Architecture:** Laravel 13 app with one Filament 5 panel mounted at `/`. Business rules live in plain PHP classes under `app/Domain/` (unit-tested without Filament); Filament resources are thin and call them. Money is integer centimes, durations are integer minutes. PDFs are rendered with dompdf from a Blade view and stored on send.

**Tech Stack:** PHP 8.4, Laravel 13, Filament 5, Pest 5, MySQL 8, barryvdh/laravel-dompdf 3.1, spatie/laravel-settings + filament/spatie-laravel-settings-plugin.

**Spec:** `docs/superpowers/specs/2026-11-21-billing-design.md` (read it first, plus `GLOSSARY.md` and `docs/adr/0001-dompdf-for-invoice-pdfs.md`).

## Review Focus

1. Time Entry where end is before or equal to start, or crosses midnight → end ≤ start rejected with a validation error; crossing midnight is valid. (Task 4)
2. Editing/deleting a Time Entry whose Task is on a **sent/paid/cancelled** Invoice, through any path (form, relation manager, direct model update) → refused. (Task 4 guard, Task 6 test)
3. Year rollover and Sent Date ordering: first invoice sent in 2027 gets `2027-001`; a Sent Date earlier than another invoice's Sent Date is refused; a draft deleted before sending leaves no gap. (Task 6)
4. Discount/rounding edge cases: percent discount producing half-centimes, discount larger than subtotal, negative Item Lines → amounts round half-up to centimes, total never silently goes below zero (validation error if total < 0 on send). (Task 6)
5. Archived Clients/Projects disappear from pickers (new Project, new Task, new Expense, new Invoice) but their existing records still display. (Tasks 3, 4, 5, 7)
